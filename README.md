# Lógica de Programación con PSeInt

Este repositorio contiene una colección de algoritmos desarrollados en **pseudocódigo estructurado** utilizando [PSeInt](http://pseint.sourceforge.net/). El objetivo de estos proyectos es demostrar habilidades fundamentales en lógica de programación, uso de estructuras de control y manejo de datos.

## Proyectos Incluidos

### 1. Conversor de Unidades (Centímetros a Metros)
*   **Archivo:** `01-conversor-cm-m/conversor.psc`
*   **Descripción:** Un algoritmo matemático simple que solicita al usuario una medida en centímetros (cm) y realiza el cálculo para convertirla y mostrarla en metros (m).
*   **Conceptos aplicados:** Entrada/Salida de datos, operadores aritméticos, declaración de variables.

### 2. Registro de Asistencia
*   **Archivo:** `02-registro-asistencia/asistencia.psc`
*   **Descripción:** Un sistema básico para registrar la asistencia de un grupo de personas. Permite ingresar nombres y marcar su estado (presente/ausente).
*   **Conceptos aplicados:** Arreglos (Vectores/Matrices), bucles (`Para` / `Mientras`), contadores lógicos.

### 3. Menú Interactivo
*   **Archivo:** `03-menu-interactivo/menu.psc`
*   **Descripción:** Una interfaz de texto que presenta múltiples opciones al usuario, ejecutando diferentes bloques de código según la opción seleccionada, y que se repite hasta que el usuario decide salir.
*   **Conceptos aplicados:** Estructura condicional múltiple (`Según`), bucles de repetición condicional (`Repetir Hasta Que`).

## Tecnologías y Herramientas
*   **Lenguaje:** Pseudocódigo estructurado.
*   **Entorno:** PSeInt (Perfil Flexible/Estricto).

## Cómo ejecutar los proyectos

1. Descarga e instala [PSeInt](http://pseint.sourceforge.net/).
2. Clona este repositorio en tu máquina local o descarga los archivos en formato `.zip`.
3. Abre el programa PSeInt y ve a `Archivo > Abrir`.
4. Selecciona cualquiera de los archivos `.psc` y presiona el botón de **Ejecutar** (o la tecla `F9`).
